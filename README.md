## What is this?

A public wiki of structured guides, specs and implementation notes for the AWFL ecosystem. Everything is organised into **folders**, and each folder holds **pages** you can browse and search.

This repository is the **read-only static mirror** of the primary site. It has no login and no server code. A scheduled GitHub Action copies the public files from the primary site into this repo, using the same paths, so every page here is also at the same path on the primary site.

## How to use it

1. Open the [mirror](https://aedtpworldawfl.github.io/awflwikidataworld/).
2. Pick a folder or use the search bar.
3. Click a page to read it. The breadcrumb (`Home > folder > page`) shows where you are.

Each page is also a normal standalone web page, so you can link to it directly.

## For search engines and AI tools

- `sitemap.xml` (and `sitemap-N.xml`) list every page on this mirror
- `llms.txt` is a plain-text map of the whole wiki for AI tools
- `robots.txt` and `.well-known/ai.txt` welcome search and AI crawlers
- Pages declare the primary site as their canonical address and this mirror as an alternate
