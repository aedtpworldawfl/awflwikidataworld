Part Of (P10)

Property ID: P10
Label: Part Of
Internal Key: part of
System: AWFLWIKIDATAWORLD
Status: Core / Relational

WHAT IS P10?
Part Of (P10) is a property that links an item to a larger entity that it belongs to or is a component of. It expresses a hierarchical or compositional relationship: the subject is a part, piece, member, or subdivision of the object. P10 answers the question: "What is this item a part of?"

HOW TO USE P10
P10 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q5 = Anloga).
2. Add a statement.
3. Select Part Of (P10) as the property.
4. Enter the value — which must be an item representing the larger entity (e.g., Q8 = Volta Region, or Q4 = Ghana).
5. Save.
The value of P10 is always a Q-item (a larger entity), never a string, number, or date.

WHERE P10 APPLIES
P10 can apply to many types of items:
- Places (city, town, district) → part of a region, state, or country.
- Organizations (department, division) → part of a larger organization.
- Creative works (song) → part of an album or EP.
- Events → part of a series or festival.
- Concepts → part of a larger field or system.
It does not apply to people (a person is not "part of" another person), nor to abstract items with no clear whole.

WHEN TO USE P10
Always use P10 when:
- You want to state that an item is a component or member of a larger whole.
- You want to establish a hierarchical relationship (e.g., city → region → country).
- You want to group items under a parent entity.
- You need AI or search systems to understand containment or membership.

Do NOT use P10 when:
- You want to state that an item is an instance of a class (use P1 instance of).
- You want to state that an item is located in a place (use P11 located in).
- You want to state that a person is a member of a group (use P17 member of).

WHY P10 MATTERS FOR AI
When an AI reads an item and sees P10 → Volta Region, it immediately knows:
- This item is part of the Volta Region.
- It can infer broader geographic or organizational context.
- It can navigate upward in a hierarchy to find the country or parent entity.
P10 is essential for building hierarchical knowledge graphs and for reasoning about containment.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing the larger entity.
- Multiple values allowed: Rare — an item is usually part of one primary whole, but can be part of multiple if it belongs to several systems.
- Required: Recommended for places, organizations, and works that are components of larger things.
- Related properties: P1 instance of (class membership), P11 located in (physical location), P17 member of (person to group), P30 group (generic group membership).

SUMMARY
P10 (Part Of) answers: "What is this item a part of?"
It is a core relational property in AWFLWIKIDATAWORLD.
Use it to link components to their wholes and build hierarchies.
