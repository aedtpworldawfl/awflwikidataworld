Instance Of (P1)

Property ID: P1
Label: Instance Of
Internal Key: instance of
System: AWFLWIKIDATAWORLD
Status: Core / Fundamental

WHAT IS P1?
Instance Of (P1) is the most fundamental property in AWFLWIKIDATAWORLD. It defines what an item is — its core category or class. Every item (Q-item) should have at least one "instance of" statement. Without P1, an item has no type, no category, and cannot be properly understood by humans or AI.
Think of P1 as the answer to the question: "What kind of thing is this?"

HOW TO USE P1
P1 is used inside an item's statement list. You add it the same way you add any property:
1. Open or create an item (e.g., Q5).
2. Add a statement.
3. Select Instance Of (P1) as the property.
4. Enter the value — which must be another item that represents a class or category (e.g., Q1 = human, Q10 = country, Q20 = company).
5. Save.
The value of P1 is always a Q-item (a class), never a string, number, or date.

WHERE P1 APPLIES
P1 applies to every item type:
- Person → human (Q1)
- Country → country (Q10)
- Company / Organization → company (Q20)
- Song → song (Q30)
- Album → album (Q31)
- City → city (Q11)
- Language → language (Q40)
- Occupation → occupation (Q50)
Note: The Q-numbers above are examples. Use the actual Q-IDs from your AWFLWIKIDATAWORLD instance.

WHEN TO USE P1
Always use P1 when:
- You create a new item.
- You want to classify an item into a category.
- You need AI or search systems to understand what the item is.

Do NOT use P1 when:
- You want to describe a relationship between two items (use other properties like P10 part of, P13 founded by, etc.).
- You want to add a label or name (use P28 name or P26 nickname).
- You want to add a date (use P5 date of birth, P14 inception, etc.).

WHY P1 MATTERS FOR AI
AI systems learn from structured data. When an AI reads an item and sees P1 → human, it immediately knows:
- This item is a person, not a place or thing.
- It can expect properties like date of birth, occupation, country.
- It should not expect properties like population or capital.
P1 is the anchor that tells AI how to interpret everything else about the item.

TECHNICAL NOTES
- Value type: Item (Q-ID)
- Multiple values allowed: Yes — an item can be instance of more than one class (e.g., a person can be both human and musical artist).
- Required: Strongly recommended for every item.
- Related properties: P39 subclass of (for classes themselves), P27 type (a looser classification).

SUMMARY
P1 (Instance Of) answers: "What is this?"
It is the foundation of every item in AWFLWIKIDATAWORLD.
Use it first. Use it always. Use it correctly.
