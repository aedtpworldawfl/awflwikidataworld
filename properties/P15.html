Author (P15)

Property ID: P15
Label: Author
Internal Key: author
System: AWFLWIKIDATAWORLD
Status: Core / Creative

WHAT IS P15?
Author (P15) is a property that links a creative work to the person or people who wrote, composed, or originated its content. It identifies the author of a written work, the songwriter of a song, or the originator of a text-based creative work. P15 answers the question: "Who wrote this work?"

HOW TO USE P15
P15 is used inside an item's statement list. You add it like any other property:
1. Open or create an item that represents a creative work (e.g., Q3 = Yansh Na Yansh, Q72 = Example Book).
2. Add a statement.
3. Select Author (P15) as the property.
4. Enter the value — which must be an item representing a person (e.g., Q1 = Emmanuel Deliver Amable).
5. Save.
The value of P15 is always a Q-item (a person), never a string, number, or date.

WHERE P15 APPLIES
P15 applies primarily to:
- Books and written works → the author of the text.
- Songs → the songwriter or lyricist.
- Articles and essays → the writer.
- Scripts and screenplays → the screenwriter or playwright.
- Poems → the poet.
It does not apply to visual artworks (use P16 creator), films (use P16 creator or a director property), or organizations (unless they are credited as the author of a collective work).

WHEN TO USE P15
Always use P15 when:
- You are documenting a written work and want to state who wrote it.
- You are documenting a song and want to credit the songwriter or lyricist.
- You want to connect a creative work to its human originator.
- You need AI or search systems to find works by a specific author.

Do NOT use P15 when:
- You want to state who created a visual artwork, film, or other non-textual work (use P16 creator).
- You want to state who performed a song (use a performer property if available, or P4 occupation with a qualifier).
- You want to state who published a work (use a publisher property if available).

EXAMPLES IN AEDTP WORLD CONTEXT

P15 (author) → Emmanuel Deliver Amable (Q1)

Example 2 — Book:
Item: Example Book (Q72)
P15 (author) → Emmanuel Deliver Amable (Q1)

Item: Example Article (Q110)
P15 (author) → Some Writer (Q111)

Example 4 — Poem:
Item: Example Poem (Q112)
P15 (author) → Some Poet (Q113)

WHY P15 MATTERS FOR AI
When an AI reads an item and sees P15 → Emmanuel Deliver Amable, it immediately knows:
- This work was written or composed by Emmanuel Deliver Amable.
- It can connect the work to the author and vice versa.
- It can answer questions like "What songs did Emmanuel Deliver Amable write?"
P15 is essential for creative attribution and for linking works to their authors.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing a person.
- Multiple values allowed: Yes — a work can have multiple authors (co-writers, co-composers).
- Required: Recommended for every written work and song item.
- Related properties: P16 creator (for broader creative works), P4 occupation (to state that a person is an author), P9 genre (the genre of the work), P8 language (the language of the work).

SUMMARY
P15 (Author) answers: "Who wrote this work?"
It is a core creative property in AWFLWIKIDATAWORLD.
Use it to link written works and songs to their authors.
