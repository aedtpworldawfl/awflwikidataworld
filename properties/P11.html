Located In (P11)

Property ID: P11
Label: Located In
Internal Key: located in
System: AWFLWIKIDATAWORLD
Status: Core / Geographic

WHAT IS P11?
Located In (P11) is a property that links an item to the place where it is physically located or situated. It identifies the geographic location of an item — which could be a city, region, country, or other place. P11 answers the question: "Where is this item located?"

HOW TO USE P11
P11 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q5 = Anloga).
2. Add a statement.
3. Select Located In (P11) as the property.
4. Enter the value — which must be an item representing a place (e.g., Q8 = Volta Region, Q4 = Ghana, Q7 = Accra).
5. Save.
The value of P11 is always a Q-item (a place), never a string, number, or date.

WHERE P11 APPLIES
P11 can apply to many types of items:
- Places (city, town, building, landmark) → located in a larger region or country.
- Organizations (company, school, church) → located in a city or country.
- Events (festival, concert) → located in a place where it takes place.
- Physical objects (monument, statue) → located in a place.
It does not apply to abstract concepts, people (use P6 place of birth for birth location, or another property for residence), or creative works (unless referring to a physical copy).

WHEN TO USE P11
Always use P11 when:
- You want to state where a place, organization, or event is physically situated.
- You want to link an item to its geographic context.
- You need AI or search systems to find items by location.

Do NOT use P11 when:
- You want to state the country of a person (use P2 country or P6 place of birth).
- You want to state what an item is part of (use P10 part of for hierarchical containment).
- You want to state a generic location (use P29 place).

EXAMPLES IN AEDTP WORLD CONTEXT
Example 1 — Place:
Item: Anloga (Q5)
P11 (located in) → Volta Region (Q8)

Example 2 — Organization:
Item: AEDTP WORLD (Q2)
P11 (located in) → Ghana (Q4)

Example 3 — Organization:
Item: AWFLWIKIDATAWORLD (Q20)
P11 (located in) → Ghana (Q4) (if physical server or office)

Example 4 — Building:
Item: Some Building (Q80)
P11 (located in) → Accra (Q7)

WHY P11 MATTERS FOR AI
When an AI reads an item and sees P11 → Volta Region, it immediately knows:
- This item is physically located in the Volta Region.
- It can infer the country (Ghana) and other geographic context.
- It can answer questions like "What organizations are located in Ghana?"
P11 is essential for geographic search, mapping, and location-based reasoning.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing a place.
- Multiple values allowed: Usually one, but can be multiple if an item spans multiple locations (e.g., a company with offices in several cities).
- Required: Recommended for any physical item with a location.
- Related properties: P10 part of (hierarchical containment), P2 country (national affiliation), P6 place of birth (for persons), P29 place (generic location).

SUMMARY
P11 (Located In) answers: "Where is this item located?"
It is a core geographic property in AWFLWIKIDATAWORLD.
Use it to link items to their physical location for geographic context.
