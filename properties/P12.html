Population (P12)

Property ID: P12
Label: Population
Internal Key: population
System: AWFLWIKIDATAWORLD
Status: Core / Demographic

WHAT IS P12?
Population (P12) is a property that links a place to the number of people living there. It records the total count of inhabitants for a city, region, country, or other geographic entity. P12 answers the question: "How many people live in this place?"

HOW TO USE P12
P12 is used inside an item's statement list. You add it like any other property:
1. Open or create an item that represents a place (e.g., Q4 = Ghana, Q7 = Accra, Q8 = Volta Region).
2. Add a statement.
3. Select Population (P12) as the property.
4. Enter the value — which must be a number (integer) representing the population count (e.g., 31000000).
5. Save.
The value of P12 is always a number, never a string, Q-item, or date.

WHERE P12 APPLIES
P12 applies primarily to:
- Country items → total population of the country.
- Region / State items → population of that administrative division.
- City / Town items → population of the urban area.
- District items → population of the district.
It does not apply to people, organizations, songs, or abstract concepts.

WHEN TO USE P12
Always use P12 when:
- You are documenting a place and want to state how many people live there.
- You want to compare populations between places.
- You need AI or search systems to sort or filter places by population size.

Do NOT use P12 when:
- You want to state the area of a place (use a different property if available, or P12 with a qualifier).
- You want to state the population of an organization (use a different property, or P12 with a qualifier).
- You want to state a date-related count (use P32 date with a qualifier).

EXAMPLES IN AEDTP WORLD CONTEXT
Example 1 — Country:
Item: Ghana (Q4)
P12 (population) → 31000000 (approximate, 2021 estimate)

Example 2 — City:
Item: Accra (Q7)
P12 (population) → 2300000

Example 3 — Region:
Item: Volta Region (Q8)
P12 (population) → 1600000

Example 4 — District:
Item: Anloga District (Q90)
P12 (population) → 95000

WHY P12 MATTERS FOR AI
When an AI reads an item and sees P12 → 31000000, it immediately knows:
- This place has about 31 million people.
- It can compare this with other countries or cities.
- It can answer questions like "What is the most populous city in Ghana?"
P12 is essential for demographic knowledge and for geographic comparisons.

TECHNICAL NOTES
- Value type: Number (integer).
- Multiple values allowed: Yes — a place can have multiple population figures for different years. In that case, use a qualifier for the year if your system supports it, or add multiple statements with dates.
- Required: Recommended for every country, region, and city item.
- Related properties: P2 country (to link a place to its country), P3 capital (for capital cities), P11 located in (for geographic context), P32 date (to specify the year of the population count).

SUMMARY
P12 (Population) answers: "How many people live in this place?"
It is a core demographic property in AWFLWIKIDATAWORLD.
Use it to link places to their population figures for demographic analysis.
