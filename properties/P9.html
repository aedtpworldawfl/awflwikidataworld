Genre (P9)

Property ID: P9
Label: Genre
Internal Key: genre
System: AWFLWIKIDATAWORLD
Status: Core / Creative

WHAT IS P9?
Genre (P9) is a property that links a creative work to its genre or style. It categorises the work into a recognised artistic, musical, literary, or cinematic category. P9 answers the question: "What genre is this work?"

HOW TO USE P9
P9 is used inside an item's statement list. You add it like any other property:
1. Open or create an item that represents a creative work (e.g., Q3 = Yansh Na Yansh).
2. Add a statement.
3. Select Genre (P9) as the property.
4. Enter the value — which must be an item representing a genre (e.g., Q60 = Afrobeat, Q61 = Hip Hop, Q62 = Drill, Q63 = R&B).
5. Save.
The value of P9 is always a Q-item (a genre), never a string, number, or date.

WHERE P9 APPLIES
P9 applies primarily to:
- Music works (songs, albums, EPs) → musical genre.
- Films and videos → cinematic genre.
- Books and written works → literary genre.
- Video games → game genre.
- Other creative works → their artistic genre.
It does not apply to people, places, organizations, or abstract concepts.

WHEN TO USE P9
Always use P9 when:
- You are documenting a song, album, or other musical work.
- You are documenting a film, book, or other creative work.
- You want to group works by style or category.
- You need AI or search systems to recommend or filter works by genre.

Do NOT use P9 when:
- You want to state the occupation of a person (use P4 occupation).
- You want to state the language of a work (use P8 language).
- You want to state the country of origin (use P2 country).

WHY P9 MATTERS FOR AI
When an AI reads an item and sees P9 → Afrobeat, it immediately knows:
- This work belongs to the Afrobeat genre.
- It can recommend similar works in the same genre.
- It can group this work with other Afrobeat songs for playlists or search results.
P9 is essential for creative works and for building recommendation systems.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing a genre.
- Multiple values allowed: Yes — a work can belong to multiple genres (e.g., Afrobeat and Hip Hop).
- Required: Recommended for every creative work item.
- Related properties: P4 occupation (for people), P8 language (for works), P15 author (for written works), P16 creator (for creative works).

SUMMARY
P9 (Genre) answers: "What genre is this work?"
It is a core creative property in AWFLWIKIDATAWORLD.
Use it to link songs, albums, films, books, and other works to their genres.
