Official Website (P7)

Property ID: P7
Label: Official Website
Internal Key: official website
System: AWFLWIKIDATAWORLD
Status: Core / External Link

WHAT IS P7?
Official Website (P7) is a property that links an item to its official website on the internet. It provides the primary, authoritative web address for a person, organization, company, creative work, or any other entity. P7 answers the question: "What is the official website for this item?"

HOW TO USE P7
P7 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q1 = Emmanuel Deliver Amable, Q2 = AEDTP WORLD).
2. Add a statement.
3. Select Official Website (P7) as the property.
4. Enter the value — which must be a URL (web address) as a string (e.g., https://aedtpworld.com).
5. Save.
The value of P7 is always a string (a URL), never a Q-item, number, or date.

WHERE P7 APPLIES
P7 can apply to many types of items:
- Person → their personal or professional website.
- Organization / Company → the company's official website.
- Creative work (song, album, film, book) → the official page for that work.
- Product → the official product page.
- Event → the official event website.
- Place → official tourism or government website.
It does not apply to abstract concepts or items that have no web presence.

WHEN TO USE P7
Always use P7 when:
- You are documenting an entity that has an official website.
- You want to provide a direct link for users to learn more.
- You need AI or search systems to find the authoritative source for an item.

Do NOT use P7 when:
- You want to link to a social media profile (use a different property, or P7 with a qualifier if your system supports it).
- You want to link to a Wikipedia page or external wiki (use a different property like "Wikipedia" or "external link").
- The website is not official (e.g., a fan site, news article, or third-party page).

EXAMPLES IN AEDTP WORLD CONTEXT
Example 1 — Company:
Item: AEDTP WORLD (Q2)
P7 (official website) → https://aedtpworld.com

Example 2 — Person:
Item: Emmanuel Deliver Amable (Q1)
P7 (official website) → https://aedtpworld.com (if that is his official site)

Example 3 — Creative work:
Item: Yansh Na Yansh (Q3)
P7 (official website) → https://aedtpworld.com/music/yansh-na-yansh (example)

Example 4 — Organization:
Item: AWFLWIKIDATAWORLD (Q20)
P7 (official website) → https://aedtpworldawfl.github.io/awflwikidataworld/

WHY P7 MATTERS FOR AI
When an AI reads an item and sees P7 → https://aedtpworld.com, it immediately knows:
- This is the official online home for the item.
- It can use this URL to fetch more information, verify facts, or provide a citation.
- It can distinguish between official sources and third-party sources.
P7 is essential for linking structured data to the live web and for verifying information.

TECHNICAL NOTES
- Value type: String (URL).
- Multiple values allowed: Usually one, but can be multiple if an entity has several official websites (e.g., different language versions, or separate sites for different purposes). In that case, use qualifiers if supported.
- Required: Recommended for any entity with a website.
- Related properties: P24 website (a more generic or secondary website), P28 name (the name of the entity), P26 nickname (alternative names).

SUMMARY
P7 (Official Website) answers: "What is the official website for this item?"
It is a core external link property in AWFLWIKIDATAWORLD.
Use it to connect items to their authoritative online presence.
