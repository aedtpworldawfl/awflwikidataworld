Language (P8)

Property ID: P8
Label: Language
Internal Key: language
System: AWFLWIKIDATAWORLD
Status: Core / Linguistic

WHAT IS P8?
Language (P8) is a property that links an item to a language. It identifies a language associated with the item — whether that item is a person, a creative work, a place, or an organization. P8 answers the question: "Which language is connected to this item?"

HOW TO USE P8
P8 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q1 = Emmanuel Deliver Amable).
2. Add a statement.
3. Select Language (P8) as the property.
4. Enter the value — which must be an item representing a language (e.g., Q50 = English, Q51 = Ewe, Q52 = French).
5. Save.
The value of P8 is always a Q-item (a language), never a string, number, or date.

WHERE P8 APPLIES
P8 can apply to many types of items:
- Person → languages spoken, written, or signed.
- Creative work (song, album, book, film) → language of the content.
- Country / Region → official or predominant languages.
- Organization / Company → working languages or official languages.
- Software / Website → language of the interface or content.
It does not apply to abstract concepts or items with no language association.

WHEN TO USE P8
Always use P8 when:
- You are documenting a person and know which languages they use.
- You are documenting a creative work and want to state its language.
- You are documenting a country or region and want to list official languages.
- You need AI or search systems to filter or group items by language.

Do NOT use P8 when:
- You want to state the country of origin (use P2 country).
- You want to state the genre of a work (use P9 genre).
- You want to state a programming language (use a separate property if available, or P8 with a qualifier if your system supports it).

WHY P8 MATTERS FOR AI
When an AI reads an item and sees P8 → English, it immediately knows:
- This item is associated with the English language.
- It can infer the language of text, speech, or content.
- It can group items by language for translation, search, or analysis.
P8 is essential for linguistic knowledge and for multilingual systems.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing a language.
- Multiple values allowed: Yes — a person can speak several languages, a country can have multiple official languages.
- Required: Recommended for person items (languages spoken) and for creative works (language of content).
- Related properties: P2 country (nationality), P4 occupation (profession), P28 name (name in a specific language), P9 genre (genre of a work).

SUMMARY
P8 (Language) answers: "Which language is connected to this item?"
It is a core linguistic property in AWFLWIKIDATAWORLD.
Use it to link people, works, places, and organizations to their languages.
