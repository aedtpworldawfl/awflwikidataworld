Country (P2)

Property ID: P2
Label: Country
Internal Key: country
System: AWFLWIKIDATAWORLD
Status: Core / Geographic

WHAT IS P2?
Country (P2) is a property that links an item to a country. It identifies the country associated with the item — whether that item is a person, place, organization, event, or creative work. P2 answers the question: "Which country is this item connected to?"

HOW TO USE P2
P2 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q1).
2. Add a statement.
3. Select Country (P2) as the property.
4. Enter the value — which must be an item representing a country (e.g., Q4 = Ghana, Q5 = Nigeria, Q6 = United States).
5. Save.
The value of P2 is always a Q-item (a country), never a string, number, or date.

WHERE P2 APPLIES
P2 can apply to many types of items:
- Person → country of citizenship or nationality
- Organization / Company → country of origin or headquarters
- Place (city, region) → country it is located in
- Event → country where it took place
- Creative work (song, album, film) → country of production or origin
- Product → country of manufacture or origin

WHEN TO USE P2
Always use P2 when:
- You want to state which country a person is from or belongs to.
- You want to state the country where an organization is based.
- You want to state the country a place belongs to.
- You need AI or search systems to group items by country.

Do NOT use P2 when:
- You want to specify a city or region (use P11 located in, or P29 place).
- You want to specify a continent or larger region (use other geographic properties).
- The item has no country association.

P2 (country) → Ghana (Q4)

Example 4 — Song:

P2 (country) → Ghana (Q4)

WHY P2 MATTERS FOR AI
When an AI reads an item and sees P2 → Ghana, it immediately knows:
- The item is associated with Ghana.
- It can infer language, culture, and geographic context.
- It can group this item with other Ghana-related items.
P2 is essential for geographic filtering, search, and knowledge graph connections.

TECHNICAL NOTES
- Value type: Item (Q-ID) representing a country.
- Multiple values allowed: Usually one, but can be multiple for dual citizenship or multiple countries of origin.
- Required: Recommended for any item with a clear country association.
- Related properties: P6 place of birth (specific city), P11 located in (broader region), P29 place (generic location).

SUMMARY
P2 (Country) answers: "Which country is this connected to?"
It is a fundamental geographic property in AWFLWIKIDATAWORLD.
Use it to link people, places, organizations, and works to their country.
