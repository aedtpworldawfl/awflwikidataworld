Inception (P14)

Property ID: P14
Label: Inception
Internal Key: inception
System: AWFLWIKIDATAWORLD
Status: Core / Temporal

WHAT IS P14?
Inception (P14) is a property that links an item to the date or time when it began, was founded, created, or came into existence. It records the starting point of an entity, organization, creative work, or any item with a definable beginning. P14 answers the question: "When did this item begin?"

HOW TO USE P14
P14 is used inside an item's statement list. You add it like any other property:
1. Open or create an item (e.g., Q2 = AEDTP WORLD).
2. Add a statement.
3. Select Inception (P14) as the property.
4. Enter the value — which must be a date in the format YYYY-MM-DD (e.g., 2024-04-14) or just a year (e.g., 2024) if the exact date is unknown.
5. Save.
The value of P14 is always a date, never a string, number, or Q-item.

WHERE P14 APPLIES
P14 can apply to many types of items:
- Organizations / Companies → date the organization was founded or established.
- Countries → date the country gained independence or was established.
- Creative works (songs, albums, books, films) → date the work was first published, released, or created.
- Events → date the event began.
- Projects → date the project started.
- Any entity with a definable beginning.
It does not apply to people (use P5 date of birth for when a person was born).

WHEN TO USE P14
Always use P14 when:
- You are documenting an organization and know when it was founded.
- You are documenting a creative work and know when it was released or created.
- You are documenting a country and know when it was established.
- You need AI or search systems to sort or filter items by their start date.

Do NOT use P14 when:
- You want to state the date a person was born (use P5 date of birth).
- You want to state the date something ended (there may be a separate property for dissolution or end date).
- You want to state a generic date that is not the beginning (use P32 date).

WHY P14 MATTERS FOR AI
When an AI reads an item and sees P14 → 2024-04-14, it immediately knows:
- This item began on April 14, 2024.
- It can calculate how long the entity has existed.
- It can place the item in a historical timeline.
- It can answer questions like "What organizations were founded in 2024?"
P14 is essential for temporal reasoning and for understanding the history of entities.

TECHNICAL NOTES
- Value type: Date (YYYY-MM-DD or YYYY).
- Multiple values allowed: Rare — an entity usually has one inception date, but can have multiple if it was re-founded or has different phases.
- Required: Recommended for every organization, country, and creative work item.
- Related properties: P13 founded by (who founded it), P38 founding date (a more specific property for exact founding dates), P32 date (generic date), P5 date of birth (for persons).

SUMMARY
P14 (Inception) answers: "When did this item begin?"
It is a core temporal property in AWFLWIKIDATAWORLD.
Use it to link organizations, countries, and creative works to their starting date.
